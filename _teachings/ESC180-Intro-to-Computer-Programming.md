## Course Overview

This course provides a comprehensive introduction to Python. Topics covered include:
- Introduction to programming in Python
- Functions
- Loops
- Data types (dictionaries, tuples, lists)
- Time complexity
- Sorting algorithms
- Search algorithms
- Recursion
- Mutability

## Textbooks

- "Python for Data Analysis" by Wes McKinney
- "Data Science from Scratch" by Joel Grus

## Personal Comments

One of the easiest first-semester classes (if you already have experience with coding). Assuming you have a basic familiarity with Python, lectures are essentially optional for the first month or two (with the exception of mutability). Content certainly picks up post-midterm/reading week, so I would recommend going to lectures once you start doing time complexity. For labs, I use them as a measure of how well I know the material. Make sure you choose a lab partner with a similar level of experience. For projects, start them early! Figuring out the edge cases can be very time consuming, and might even require refactoring of most of your code. For extra practice, I recommend previous midterms (as always), along with Project Euler, Code Wars, and Leetcode. They may be a bit overkill, but they are a very fun and relevant way to study.
